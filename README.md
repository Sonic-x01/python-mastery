# Python Mastery — دليل بايثون التفاعلي 🐍

صفحة ويب عربية (RTL) لتعلّم **أساسيات بايثون من الصفر** بأسلوب عملي: شرح مبسّط، أمثلة قابلة للتشغيل، جداول مرجعية، وتمارين تفاعلية مع تصحيح فوري.

> جميع الأكواد وأسماء المتغيرات والمخرجات مكتوبة **بالإنجليزية**، بينما الشرح والتعليقات التعليمية **بالعربية**.

## المحتوى

- **17 مرحلة** مرتبة من التثبيت حتى المشاريع:
  المتغيرات، النصوص، الأرقام، الشروط، الحلقات، القوائم، Tuple/Set/Dict، الدوال،
  Comprehensions والمولدات، الملفات وJSON/CSV، الاستثناءات، المكتبات، OOP،
  مواضيع احترافية، مشاريع، وCheat Sheet.
- **58 سؤالًا تفاعليًا** مع شرح الإجابة الصحيحة.
- **25 تحدي كود** بمخرجات متوقعة — لا يُحتسب التحدي إلا إذا طابقت مخرجاته المطلوب.
- **أكثر من 150 مثالًا ومرجعًا**، منها 55 مثالًا قابلاً للتشغيل بضغطة زر.
- تتبّع تلقائي للتقدم في المتصفح، نسبة إنجاز، وتمييز المراحل المكتملة.
- وضع داكن/فاتح، بحث في الدروس، وCheat Sheet قابل للبحث.
- تصميم متجاوب للموبايل + طباعة/PDF.

## التشغيل (الطريقة الموصى بها)

### Windows

دبل كليك على **`start.bat`**.

هذا يشغّل خادمًا محليًا صغيرًا ويفتح المتصفح تلقائيًا على:

```
http://127.0.0.1:8765/
```

### يدويًا (أي نظام)

```bash
python server.py
```

أو بدون فتح المتصفح:

```bash
python server.py --no-browser
```

> يتطلب Python 3.9 أو أحدث. لا توجد أي مكتبات خارجية مطلوبة.

## تشغيل الكود داخل الصفحة

الصفحة تدعم طريقتين:

1. **الخادم المحلي (الأفضل):** عند تشغيلها عبر `start.bat` أو `server.py`، تُنفَّذ الأكواد
   ببايثون المثبّت على جهازك عبر `POST /api/run` — يعمل **بدون إنترنت** وبسرعة.
2. **Pyodide (احتياطي):** إذا فتحت `index.html` مباشرة، تحاول الصفحة تحميل
   [Pyodide](https://pyodide.org/) من الإنترنت لتشغيل الكود داخل المتصفح.

إذا لم يعمل التشغيل، افتح الصفحة عبر `start.bat` بدل فتح الملف مباشرة.

## كيف يعمل التصحيح؟

- **الأسئلة:** تُقارن الإجابة بالفهرس الصحيح، ويظهر شرح للإجابة.
- **تحديات الكود:** يُنفَّذ الحل ويُقارن الناتج (stdout) بالمخرجات المتوقعة بعد توحيد
  نهايات السطور. الأخطاء تظهر كـ traceback واضح.
- **التقدّم:** يُحفظ في `localStorage` تحت المفتاح `pythonCourse.v1`، ويمكن تصفيره من
  الشريط الجانبي.

## ملاحظات وأمان

- خادم التشغيل يستمع على `127.0.0.1` فقط، ومخصص للاستخدام التعليمي الشخصي.
- **لا تعرّض المنفذ للشبكة أو للإنترنت**: واجهة `/api/run` تنفّذ الكود الذي يُرسل إليها.
- كل تشغيل يتم في مجلد مؤقت داخل `.runner/` ويُحذف بعد الانتهاء.
- الأكواد التي تستخدم `input()` لا تعمل داخل الصفحة (لا يوجد طرفية تفاعلية)؛ جرّبها على
  جهازك من ملف `.py`.
- الأكواد تُشغَّل بمهلة 8 ثوانٍ لمنع الحلقات اللانهائية.
