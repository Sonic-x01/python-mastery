# Python Mastery — دليل بايثون التفاعلي 🐍

صفحة ويب عربية (RTL) لتعلّم **أساسيات بايثون من الصفر** بأسلوب عملي: شرح مبسّط، أمثلة قابلة للتشغيل، جداول مرجعية، وتمارين تفاعلية مع تصحيح فوري.

> جميع الأكواد وأسماء المتغيرات والمخرجات مكتوبة **بالإنجليزية**، بينما الشرح والتعليقات التعليمية **بالعربية**.

## المحتوى

- **17 مرحلة** مرتبة من التثبيت حتى المشاريع:
  المتغيرات، النصوص، الأرقام، الشروط، الحلقات، القوائم، Tuple/Set/Dict، الدوال،
  Comprehensions والمولدات، الملفات وJSON/CSV، الاستثناءات، المكتبات، OOP،
  مواضيع احترافية، مشاريع، وCheat Sheet.
- **58 سؤالًا تفاعليًا** مع شرح الإجابة الصحيحة.
- **25 تحدي كود** بمخرجات متوقعة — لا يُحتسب التحدي إلا إذا طابقت مخرجاته المطلوب.
- **أكثر من 150 مثالًا ومرجعًا**، منها 55 مثالًا قابلاً للتشغيل بضغطة زر.
- تتبّع تلقائي للتقدم في المتصفح، نسبة إنجاز، وتمييز المراحل المكتملة.
- وضع داكن/فاتح، بحث في الدروس، وCheat Sheet قابل للبحث.
- تصميم متجاوب للموبايل + طباعة/PDF.
